In this course, students will learn the procedures, protocols and best practices that a DevOps
engineer brings to a workplace environment to increase productivity. Analyze and evaluate
various developer operation implementations available and implement hands-on work using an
industry-standard toolkit. Create solutions to complex business problems by adhering to the core
responsibilities of DevOps
The DevOps course teaches students how to use Git and GitHub for version control and collaboration
Students learn to work with branches, commits, and pull requests to manage changes in a shared repository
The course also introduces continuous integration and continuous delivery, including automated workflows using tools such as GitHub Actions
Through practical assignments, students gain experience managing Git repositories, tracking changes, and collaborating on shared projects
These activities help students understand how version control and automated workflows are used in professional software development environments
