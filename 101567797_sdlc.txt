Software Development Life Cycle (SDLC) The Software Development Life Cycle is a process used by developers to plan, create, test and maintain software applications. It helps teams stay organized and ensures that software meets the needs of its users. The SDLC includes several stages such as planning, gathering requirements, designing the system, development, testing, deployment and maintenance. Each stage plays an important role in making sure the final product works as expected. DevOps improves the SDLC by encouraging collaboration between developers and operations teams. It also introduces automation to make testing and deployment faster and more reliable. In COMP3104 we learn how tools like Git and GitHub help developers manage changes throughout the development process. By using branches, commits and pull requests, teams can work on different parts of a project while keeping everything organized.
Testing is an important part of the SDLC because it helps developers find problems before software reaches users. Different types of testing can be used to check whether an application works correctly and meets its requirements. Finding issues early can save time and make the final product more reliable.

DevOps plays an important role in the SDLC because it helps connect the development and operations stages. Instead of waiting until the end of a project to test and deploy software, teams can use automated tools throughout development. This allows developers to identify problems earlier, release updates more frequently and improve the overall quality of their applications.
